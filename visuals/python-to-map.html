1. 1. Make a shapely polygon

    Any shapely geometry works.

    poly = Polygon([(-122.45, 37.75), (-122.40, 37.75),
                (-122.40, 37.79), (-122.45, 37.79)])

  2. 2. Push it onto the map

    add_geometry draws it on the Geoman layer, so it is editable.

    geo = GeoCanvas(center=(37.77, -122.42), zoom=12)
geo.add_geometry(poly)
geo

  3. 3. Edit it by hand

    Drag a corner on the map. The dashed line is where it started.

    (drag the top-right corner)

  4. 4. Read it back

    The map is the source of truth, so you get the edited shape.

    geo.wkt   # the edited polygon, as WKT
geo.geometries   # or as shapely objects
