1. 1. Measure the gap

    The gap is the shortest distance from one polygon edge to another.

    gap(A, B) < gap(D, C)

  2. 2. Compare it to epsilon

    Draw a ring of radius epsilon around a polygon. Anything the ring touches is a neighbor.

    epsilon = 50

  3. 3. Count neighbors

    A core polygon needs at least 3 neighbors, counting itself. B has A, D, and itself.

    --min-samples 3

  4. 4. Grow the cluster

    A and D are not core, but they touch core B, so they join its cluster. C touches nothing and is an outlier.

    cluster_id: A, B, D = 0
cluster_id: C = null
