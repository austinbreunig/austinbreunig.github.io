bap

BAP (Big Ass Polygons): clusters nearby polygons and wraps each cluster in a tight, orthogonal boundary.

github.com/austinbreunig/bap

It's for GIS folk who may have too many polygons and instead want a few big ass ones.

Delineating new boundaries on aggregate fields is a common pattern in organizing and restructuring geospatial data. I wanted to work on building a clean interface between the core algorithm (DBSCAN-like clustering) and a CLI. The package is simple, but user-friendly. The simplicity of the package and workflow was intentional, as the core intention was to showcase (and test) the functionality of plumber (i.e. a pipeline framework, used to scale geospatial workflows).

How it works

Validate, project to UTM, cluster, boundary, tightness gate (>= 0.75), IDs, project back.

Scale

1,000,000 polygons in 254 s, 1.5 GB peak memory.
