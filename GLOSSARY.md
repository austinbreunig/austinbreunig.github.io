# Portfolio Website

The personal portfolio site for Austin Breunig: a landing page, one page per public project, and a resume page.

## Language

**Project page**:
The page for one public repo. Its title and summary come first and its repo link last; the sections between them are decided per project in its grilling session.
_Avoid_: Case study, project writeup

**Guided visual**:
An interactive explainer made by an agent with the `human` skill and embedded in a project page by `<iframe>`.
_Avoid_: Diagram, infographic, embed

**Screenshot**:
A still image the user takes of the project.
_Avoid_: Image, capture

**Key prompts**:
The fixed questions a grilling session asks to draw out the user's words. Story and tools are prompts only, not page sections.
_Avoid_: Interview questions, outline
